# React Inline Styling

This project covers inline styling, Aphrodite CSS-in-JS, responsive design with media queries, and CSS animations in React.

## Tasks

- **task_0**: Inline styling with background colors on CourseListRow
- **task_1**: Aphrodite CSS-in-JS for App, Header, Login, Notifications, CourseList, BodySectionWithMarginBottom
- **task_2**: Conditionally applying Aphrodite styles to NotificationItem and CourseListRow
- **task_3**: Responsive design with media queries for Login, Notifications, NotificationItem
- **task_4**: CSS animations (opacity + bounce) on Notifications menu item
